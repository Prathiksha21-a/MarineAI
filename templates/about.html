About MarineAI

Project Overview

MarineAI is a deep learning dashboard for automated fish detection, abundance assessment, large-fish identification, and interpretable marine image analysis in support of sustainable fisheries.

Technologies

  • YOLOv11
  • Flask
  • OpenCV
  • PyTorch
  • LayerCAM

Features

  • Fish Detection
  • Fish Abundance
  • Large Fish Detection
  • Live Detection
  • Explainable AI

Future Scope

Future work can add continuous underwater video analysis, ocean-sensor integration, cloud deployment, broader species models, and population-level trend reporting.
